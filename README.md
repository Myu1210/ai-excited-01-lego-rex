# The Lego T. Rex Woke Up

A make.fun ai-excited-01 entry: a giant T. rex built from glossy plastic toy bricks lunging out of a toy box in a kid's bedroom at dusk, rendered by a pure stdlib TypeScript rasterizer. Fully seeded — two runs write byte-identical 1024x1024 PNGs, with no text in the image.

## Run

`node main.ts` — writes the PNG to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Node 22, no dependencies.
